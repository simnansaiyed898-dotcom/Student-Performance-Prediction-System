# 🎓 Student Performance Prediction System

A real-world style **Data Science + Machine Learning web application** that predicts a student's estimated final score and Pass/Fail probability from academic and lifestyle information.

## ✨ Features

- Interactive Streamlit dashboard
- Final-score prediction using regression
- Pass/Fail probability using classification
- Performance band and risk level
- Personalized improvement suggestions
- Dataset analytics and sample records
- Model comparison and evaluation metrics
- Feature-importance visualization
- Downloadable prediction report (CSV)
- Reproducible training pipeline
- Clear separation between data, models, charts, and application code

## 🧠 ML Workflow

```text
Student Input
     ↓
Data Preprocessing
     ↓
Regression + Classification Models
     ↓
Predicted Score + Pass Probability
     ↓
Performance Band + Risk Level
     ↓
Actionable Suggestions
```

## 🚀 Run the Project

### 1. Create an environment

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

### 2. Install dependencies

```bash
pip install -r requirements.txt
```

### 3. Generate demo data (optional)

```bash
python generate_data.py
```

### 4. Train the models

```bash
python train_model.py
```

### 5. Start the application

```bash
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal.

## 📌 Demo Flow for College Presentation

1. Open **Prediction**.
2. Enter attendance, previous grade, study hours, absences, failures, sleep, and other details.
3. Click **Predict Performance**.
4. Explain the predicted score and pass probability.
5. Show the risk level and recommended actions.
6. Open **Analytics** to demonstrate the dataset.
7. Open **Model Performance** to explain MAE, RMSE, R², Accuracy, Precision, Recall and F1.
8. Download the prediction report if required.

## ⚠️ Data Note

The included dataset is synthetic demo data generated by `generate_data.py`. It is suitable for demonstrating the software pipeline, but it should not be presented as evidence about real students. For an actual institutional deployment, use an approved, documented dataset and validate the model on representative real data.
